# NOVA v7.110 - phone test list (Parts 1-7). Kuch bhi PASS tabhi likhna jab phone par dekha ho.

Pehle: GitHub > Actions > build.yml > Run workflow > APK install. Branch sirf `main`.

## Part 1 - bina baar-baar poochhe kaam
1. "Nova, Chrome me weather dekh" -> bina "haan/na" ke chalna chahiye.
2. "Nova, kisi ko paise bhej" -> RUKNA chahiye, bolna "haan" tabhi aage.

## Part 2-3 - route yaad + doosra rasta
3. Wahi job 2-3 baar chalao -> Settings card me route note dikhe.
4. Ek app band/blocked ho to NOVA doosra safe rasta try kare, bataye kaunsa.

## Part 4 - website
5. "Nova, amazon.in kholo aur X search kar" -> page padhe, steps bataye. CAPTCHA/OTP aaye to ruk kar bole "ye aap karo".

## Part 5 - saved login
6. Gmail/Chrome jahan pehle se login hai wahan kaam ho. Login nahi hai -> bole "login aap karo". Password NOVA kabhi na maange/na likhe.

## Part 6 - site seekh
7. Kisi site par login wall aaye -> Settings seekha-hua me "login wall" ginti badhe.

## Part 7 - bada brain + seekha hua
8. Settings > card "BADA BRAIN + NOVA NE KYA SEEKHA" dikhe. 8 GB+ phone par 3B "SUGGESTED"; kam RAM par "RAM kam" line.
9. DOWNLOAD ek tap -> kuch download na ho, sirf "PAKKA?" dikhe. Dusra tap (Wi-Fi par) -> progress %.
10. Download khatam -> "Ho gaya (jaanch ke saath)". Phir koi sawal poochho; jawab aaye (dheema ho sakta hai, batana).
11. SAB SEEKH MITAO -> confirm -> "3 / 3" aur summary khali. Chat/keys/settings na mitein.

Result bhejo: har number ke aage PASS / FAIL + screenshot.
