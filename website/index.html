Privacy & Security

  • API keys phone me hi rehte hain — Android Keystore (AES-256-GCM) me encrypted, kabhi kisi server par nahi jaate (tests se enforce hota hai).
  • Phone ↔ laptop baat encrypted — relay (ntfy.sh) ko sirf random topic naam + ciphertext dikhta hai.
  • Cloud brain self-hosted hai — data aapke apne server par; memory/tasks ka text family key se seal hota hai, server ko plaintext nahi dikhta.
  • Private facts kabhi sync nahi hote — sirf un device par rehte hain jahan bane.
  • HARD DENY — bank/payment/password/OTP screens par automation blocked; delete/format/shutdown jaise commands mana.
  • Ye website static hai: koi tracking, koi cookie, koi ad nahi.
