## 6. PART 13 : REAL ANALYSIS (vision AI + gehri web search, sach, kuch invent nahi)

COMPOSE: report: summary, kya dikha, likha hua text, jaanch ke dawe (source ke saath), kya verify NAHI hua, confidence (low / medium / high, wajah ke saath), limits.
- Kuch nahi invent: jahan source nahi mila wahan "nahi mila" likho. Insaan ko shakal se pehchaan kar naam nahi batana. Nuksaan pahunchane wali jankari (hathiyar banana, aadi) par saaf mana. Protected / private screen ki file ho to saaf mana.
