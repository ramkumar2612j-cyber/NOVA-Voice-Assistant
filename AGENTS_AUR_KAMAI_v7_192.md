# JARVIS - kaun kaun se agents hain aur asli kamai mein kaun kya kar sakta hai (v7.192)

Sach pehle: Jarvis khud paisa nahi kamata. Wo boss ke dhandhe ka kaam (customer dhoondna, jawab dena, order lena, post karna, yaad dilana) sasta aur tez karta hai. Kamai tab hoti hai jab boss ke paas asli product, sahi rate aur delivery ho. Paisa / bank / password / OTP / PIN / CVV wale kaam Jarvis HAMESHA mana karta hai.

## 1. Seedha dhandhe ke agents (kamai se jude)
| Agent | Kya karta hai | Kamai mein kaise kaam aata hai | Kya chahiye / limit |
|---|---|---|---|
| Leads dhoondna (LeadFinder) | shehar + dhandhe ke public business (naam, phone, website) dhoondta hai, LeadStore mein rakhta hai, har ek ka draft message banata hai | naye customers / clients ki list | Google Places key (BIZ / SetUp); roz limit; draft bhejna boss ki approval se |
| Autopilot concierge | WhatsApp / Instagram par customer ko jawab, order leta hai (item, size, qty, naam, phone, pata), confirm par boss ko batata hai | order miss nahi hote, raat ko bhi jawab | Autopilot ON + chat app ke notification; Jarvis kabhi price / discount / stock / delivery date khud nahi banata |
| Autopilot posting | group mein aayi photo / video ko website, Instagram, YouTube par post karta hai, best time chunta hai | roz ka content bina mehnat ke | GitHub / Instagram / YouTube token (AUTOPILOT tab) |
| Offer / coupon | website par aur chat mein ek hi offer lagata hai | discount ka sahi jawab, sale | Autopilot setup |
| Business watch (WaBiz) | WhatsApp Business ke chats par catalogue se jawab (rate, size, delivery) | customer ko turant jawab | boss ka catalogue; abhi approval mode (khud reply alag se ON) |
| Website banana + publish | restaurant / shop / portfolio ki website banata aur live karta hai | online dukaan / enquiry page | GitHub / Vercel token; order button WhatsApp / mailto kholta hai (server nahi) |
| Payment QR | customer ke liye boss ka UPI QR screen dikhata hai | advance / payment lene ka aasan tareeka | boss ka apna UPI; Jarvis paisa khud nahi bhejta |
| Delivery yaad | confirm order par delivery ka wada yaad rakhta hai, waqt par bolta hai | late delivery se bachav | BIZ profile |
| Aaj ka business (L4 card) | aaj ke orders, leads, autopilot, aakhri report ek jagah; naye order / lead par card | roz ka haal 5 second mein | upar ke agents ka data |
| Call agent | boss ki taraf se phone karke sandesh deta / table book karta | follow-up, supplier / customer calls | call permission; boss ki bataayi baat hi bolta hai |
| Photo / video / app banana | product photo, reel edit, chhoti app / calendar | content aur chhote tools | free AI chain (key) |

## 2. Madad ke agents (kamai ko support)
Screen dekhna, video / reel analyse, camera se pehchanna, seekhna, kai app kholna, laptop par kaam, lamba agent (app / website mein kai kadam). Ye time bachate hain, seedha paisa nahi laate.

## 3. Jo kamai ka rasta NAHI hai
- Trading (TradeEngine): sirf DEMO / salah; Jarvis khud trade nahi lagata. Ise kamai ka zariya mat maano.
- Skfashions142 (Lovable) website se seedha order: abhi code mein backend nahi. Orders abhi WhatsApp / Instagram chat se aate hain. Shopify / WooCommerce hoti to L4 card par website orders bhi aate.

## 4. Asli kamai ke liye boss ke 5 kaam (ek-ek karke)
1. `jarvis biz product / price / city / category` bharo (BIZ profile) - leads isi se dhoondte hain.
2. Google Places key daalo (leads ke liye).
3. AUTOPILOT tab: group + website + tokens + concierge ON.
4. Apna catalogue (rate, size, delivery) WaBiz mein daalo.
5. Roz subah launcher ka "Aaj ka business" card dekho, "Report sunao" dabao, aur naye leads ke drafts khud approve karke bhejo.
